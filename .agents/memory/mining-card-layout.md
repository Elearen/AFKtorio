---
name: Mining card layout
description: Shared visual and interaction pattern for mining resource cards.
---

Mining resource cards follow the Production card hierarchy: resource header with status and machine count, collection panel, operating metrics, progress panels, and bottom actions.

**Why:** Keeping both catalogs structurally consistent makes the incremental loop easier to scan while preserving the distinct mining controls.

**How to apply:** Keep manual collection available for solid resources alongside active automated drills; fluids and uranium remain machine-only where the simulation requires it.
