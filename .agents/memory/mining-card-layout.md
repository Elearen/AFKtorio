---
name: Mining card layout
description: Shared visual and interaction pattern for mining resource cards.
---

Mining resource cards use the Science recipe hierarchy: resource header with status and machine count, a compact collection flow directly under the heading, operating metrics, progress panels, and bottom actions.

**Why:** Keeping Mining, Production, and Science flows structurally consistent makes the incremental loop easier to scan while preserving the distinct mining controls.

**How to apply:** Keep manual collection available for solid resources alongside active automated drills; fluids and uranium remain machine-only where the simulation requires it. Keep collection-specific advisories and controls below the shared flow.
